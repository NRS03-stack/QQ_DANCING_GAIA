# QQ-Dancing Gaia 🌍✨

> **NASA Space Apps Challenge 2026 Submission**

## 📌 Overview
**QQ-Dancing Gaia** is an interactive, real-time Earth observation web dashboard designed to monitor global environmental hazards, microclimate metrics, and radar imagery. By unifying scattered satellite datasets into a single visual interface, the platform empowers researchers, educators, and citizens to analyze planet-wide environmental shifts at a glance.

---

## 🚀 Key Features
* **Live Hazard Tracking:** Integrates NASA's EONET API for real-time tracking of wildfires, severe storms, and natural hazards.
* **Microclimate Telemetry:** Fetches dynamic Air Quality (AQI), Soil Moisture, NDVI (Vegetation Index), and Thermal Output via Open-Meteo APIs.
* **Advanced Spatial Mapping:** Interactive map interface built with Leaflet.js featuring NISAR L-Band and Sentinel-1 SAR radar overlays.

---

## 🛠️ Tech Stack & Data Sources
* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Leaflet.js
* **APIs & Data:**
  * [NASA EONET API](https://eonet.gsfc.nasa.gov/) (Earth Observatory Natural Event Tracking)
  * [Open-Meteo API](https://open-meteo.com/) (Weather & Air Quality Data)
  * Sentinel-1 & NISAR SAR Radar Layers
